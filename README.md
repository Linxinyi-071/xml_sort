# XML 排序工具 (SortTool / SortUndo) — 使用说明文档

## 一、痛点

在文档本地化和翻译管理流程中，从翻译系统导出的 XML 文件通常以原始文件名命名，与手册目录架构不一致，存在以下痛点：

| 痛点 | 描述 |
|------|------|
| 📄 **文件无序** | 导出的 XML 文件命名不统一，无法按目录架构顺序排列 |
| ⏱️ **效率低下** | 译员在翻译时需手动定位各个 XML 文件在手册中的位置，无法按照目录架构进行翻译 |
| 🔙 **操作复杂** | 传统 GUI 程序需用户手动输入文件夹路径和目标路径，操作繁琐耗时长 |

## 二、用途

**XML 排序工具（SortTool）** 专为解决上述痛点设计，核心用途包括：

- 📂 **一键排序**：将目标文件夹拖拽到程序图标上，自动目录架构给 XML 文件添加序号前缀，进行排序
- 🔍 **智能匹配**：自动解析目标文件夹中的 `.xlf` 目录架构文件，建立 XML 文件与目录架构的对应关系
- 🔤 **多级匹配**：优先精确匹配，无法精确匹配时自动采用关键词重叠度最高的翻译名称
- 🔙 **一键还原**：配套 **SortUndo** 工具可一键去掉序号前缀，恢复原始文件名

## 三、效果

### 排序前

![排序前](before.png)

目标文件夹中的 XML 文件按命名排序，但与手册目录架构中的顺序不一致。译员无法按照目录架构顺序翻译文件。

### 排序后

![排序后](after.png)

目标文件夹中的 XML 文件按照 XLF 文件中的目录架构进行排序，在每个文件命名前添加数字序号前缀，确保译员可以按照目录架构顺序翻译文件。

### SortUndo 还原后

将排序后的目标文件夹拖动到**SortUndo**程序图标上，一键去掉序号前缀，恢复原始文件名。

> ✅ 一键还原为原始文件名，与导出时完全一致。

## 四、使用方法

### 方式一：拖拽操作（推荐）

![使用方法](method.gif)

1. **启动排序**：
   - 将目标文件夹（包含 `.xml`、`.xlf` 文件）**拖拽到 `SortTool.exe` 图标上**
   - 程序自动开始处理，完成后弹出提示框显示处理结果

2. **一键还原**：
   - 翻译完成后，将已排序的文件夹**拖拽到 `SortUndo.exe` 图标上**
   - 程序自动去掉所有 XML 文件前面的序号前缀，恢复原始名称

### 方式二：命令行模式

```bash
SortTool.exe "文件夹路径"
SortUndo.exe "文件夹路径"
```

**参数说明：**

| 参数 | 说明 |
|------|------|
| 文件夹路径 | 包含待处理文件的文件夹路径 |

## 五、输入文件要求

目标文件夹中需同时包含以下文件：

| 文件类型 | 说明 |
|----------|------|
| `*.xml` | 待排序的 XML 文件，文件名需以 `T` 开头（如 `T1001.xml`） |
| `*.xlf` | XLF 翻译文件，定义章节的顺序 |

## 六、运行环境

- **操作系统**：Windows 7 及以上
- **依赖**：无需安装 Python，双击 exe 即可运行
- **文件要求**：目标文件夹需包含 `.log` 和 `.xlf` 文件
